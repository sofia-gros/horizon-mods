# Clear tinted glass candidate

At horizon-mods `2f022395`, the pinned TConstruct `f4e77d43` item tag `forge:glass/tinted` requires `tconstruct:clear_tinted_glass`. Its absence made the entire tag unresolved even when Forge supplied vanilla tinted glass. This candidate registers the original block and block item using Horizon's `minecraft:tinted_glass` template, adds self-drop loot, and imports the pinned source texture and 15 connected variants. It adds the block to the existing connected texture atlas and mesh handling. It does not modify the original tag or make required entries optional. Other packs' tag contributions and missing required entries still follow the existing resolver.

The retained original `smeltery/casting/amethyst/glass` recipe outputs this block, consumes one `forge:glass/colorless` cast, costs 200 mB molten amethyst and cools for 97 ticks. Registering the output allows that existing recipe to target a registered item; it does not add a separate recipe. The source tag can now include both registered vanilla tinted glass and the new item, subject to normal pack layering and live registry state. `forge:wither_bones` is separate and remains unresolved if Necrotic Bone is unavailable.

A pre-existing local host binary prepared a resource tree successfully and produced both a block and BlockItem with this identifier, retaining the source casting recipe. The exact candidate mixins were not built into that binary. Scoped tests cover source recipe constants, expected assets, connected-glass helper behavior, and vanilla template choice. They do not establish actual light blocking, connected-face rendering, survival drops, fluid/heat consumption, save/reload, multiplayer or the exact integrated build. Verify those in SP and LAN, including both tinted-glass casts and user pack overrides, before calling this complete.

All 16 imported textures were checked independently against the GitHub blob IDs at the pinned `f4e77d43f39ba1047bf93ae816b7e1beaab514c2` revision. The packaged `.hmod` was inspected: all 16 textures match the candidate files, and `assets/tconstruct/licenses/tconstruct.txt` contains the byte-identical TConstruct MIT license and copyright. This confirms packaging and provenance, not integrated compilation, actual light blocking or live rendering.
