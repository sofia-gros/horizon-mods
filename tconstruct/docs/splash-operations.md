# Restricted splashing recipe candidate

This is an unverified candidate on the #298 integration, not a completed implementation or a gameplay pass. The original Station recipe is enabled only for the four source staffs and melting pan. It checks the source ingredients, including a supported empty portable tank, consumes an ability slot and adds 1,000 mB tool capacity per level. The ordinary recipe remains unavailable for other source tools. Adding the modifier is subject to the existing Station transaction, slot and tool rebuild checks.

The following describes intended operation after installing it and filling the tool, subject to the exact tool interaction toggle and current target restrictions:

- Right-clicking a block can use supported fire, snow, glow, known non-instant potion-cloud and conditional herbicide forms. Glowstone's supported cloud and glow placement use the maximum successful fluid amount once. Missing required tags, unsupported predicates and unknown forms refuse the effect. Potion-tagged fluid is held on the restricted LAN path.
- Clicking supported mobs can apply recognized non-instant status effects, poison removal and hunger-independent actions; source milk additionally cures poison from an unequipped supported mob with no other effects. Burning non-water-sensitive supported mobs can be extinguished with a full water effect level. The independent slurping path also supports limited self milk cure and self water extinguish. Strong Bones/calcifiable equipment, other milk-curative effects, instant potion effects and sensitive-target water damage are not covered.
- Player targets are restricted to the existing supported guest/status paths. Unknown target types, the held partial-fluid ordering case with three or more targets, unsupported status/metadata forms and tagged LAN transfers are refused before fluid is consumed by that effect. Source lava entity damage/ignition, water-sensitive damage, water's drop-producing block break and other unimplemented source effects remain outside this candidate. A normal interaction may still run if the mod does not claim it.

Immersive Engineering concrete and redstone acid have `forge:mod_loaded` conditions and are not selected in the standard environment without that mod. An unknown mod state is also not permission to select them.

On the exact integrated head, the test owner must verify the normal Station recipe and all five ingredients, empty/filled/malformed tank, slot cost, repeated levels and capacity rebuild, item/remaining-fluid preservation on failed craft, supported use and unsupported-effect refusal without fluid loss, real target identity, cooldown/wear, save/reload, SP and LAN. Verify vanilla water/lava negatives and source-tag resolution with the real installed pack. Formal apply, type/build, package, UI and gameplay are pending; the ability must not be described as full source parity.
