# Connected glass

Connected glass and panes are being prepared for Horizon. Their appearance changes when matching blocks touch. The current implementation has not yet been verified in the game.

The preparation uses the original textures, colored glass models, and pane layouts. It registers these blocks in the Tinkers blocks Creative tab and selects face textures using neighboring blocks. Placement, appearance, collision, drops, saving and multiplayer still need game validation.

Smeltery behavior, material-dependent anvils, and custom storage are separate work. The connected appearance is not complete until it has been checked in the game at boundaries and with different neighboring blocks.
