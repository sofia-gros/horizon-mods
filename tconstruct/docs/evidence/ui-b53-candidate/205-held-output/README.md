# Casting tank output with another held item

Same limited integrated client, resources, #205 inclusion and corrections as [the creative casting tank fixture](../205-creative-tank/README.md); not an unmodified exact-head build. In a fresh survival fixture, the upper tank face accepted a water bucket and processed it. The player then held dirt and clicked the upper face: dirt stayed in hand and the empty bucket was received into inventory. The image is an actual client capture and the log records the item states.
