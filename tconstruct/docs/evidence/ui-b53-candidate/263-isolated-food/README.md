# Bacon food on isolated integration

Same limited integration, generated resources, client SHA and corrections as [the Bacon repair fixture](../263-isolated-tasty/README.md). This is not a whole exact-head build.

A copied disposable world had its player's saved food level deliberately set from 20 to 10. In survival while looking away from blocks, using one Bacon increased food from 10 to 14 and consumed the item. Actual client screenshots and control log are included. Generated item data reports nutrition 4 and saturation 0.6; saturation was not measured in the running game. Other PR-wide gates remain open.
