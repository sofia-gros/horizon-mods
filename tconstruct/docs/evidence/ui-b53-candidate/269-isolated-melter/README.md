# Isolated #265/#269 Melter display comparison

The fixed upstream feature changes from #265 `ef99be3d9ab139fcb7a54976ca5f0ad2be9df7f2` and #269 `ac3af2fc4979a8214bfc6897b7245723a13dd2b0`, plus #263 content, were applied to the earlier cc868cdb integration. Four Melter feature source files match the #269 head byte-for-byte. The official Mixins tool applied this limited bundle, and the client built with host b53cfcd14eab7b6ed2fe91a3a3773d7415402ab9 and Mixins ddd9700b21997c95d95ac6ee5ecafe3830cf622a. Isolated namespace, Pluto comment and host pin changes remain; see `ui-pr269-isolated-provenance.md` for patch hashes. Client SHA-256 `7b911c13d230d3b4c7f444c5f155ad6073853164d08d8748d8510888ac7d569b`; ctl SHA-256 `76be463390faf708d915dcf9ae06b470b611b0f53a2ed362234ca956b2ae7467`. Resource preparation used this client and the isolated #263 content. The complete #269 head could not apply because of a separate unsupported Splash injection context, so **this is not a full exact-head integration pass**.

Using the same initial copied world and procedure as [the pre-fix baseline](../melter-input-local-remote-baseline/README.md), local UI insertion changed the host block entity from 8 to 9 copper ingots. The local screen displayed molten copper and its 180 mB tooltip; the LAN guest screen displayed 360 mB and retained its tooltip after close/reopen. Guest chest and inventory screens appeared normally. Simulation ran during the test: live contents later had 7 ingots, and after orderly shutdown the host save contained 7 ingots and 360 mB molten copper. All images are actual client captures. This supports the isolated display/tooltip fix on the tested path; additional head-wide and independent gates remain.
