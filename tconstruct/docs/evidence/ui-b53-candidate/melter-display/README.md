# Melter display and persisted state

Fixed combined candidate and isolated build/content corrections as documented in [the lower-tank fixture](../205-lower-tank/README.md); not an unmodified candidate. In a fresh creative world with a solid floor under the player, a heater was initialized, and 2 coal and 10 copper ingots were inserted. Tick rate was set to 200, then 400 ticks elapsed. The menu before waiting contained copper and coal; afterwards and after reopening it reported no slots and the shown Melter GUI was empty. `data get block` returned an empty live `Items` list, but this host accessor does not expose the machine's chunk-only metadata. After orderly client stop, decoding chunk (0,0) in this disposable save found the Melter metadata tank `{amount: 900, fluid: tconstruct:molten_copper}`. Thus the molten fluid was preserved in this reproduction; the apparent empty screen cannot prove fluid loss. Saved machine extracts, control log, actual screenshots and reproducible scripts are included. This does not establish whether the screen is stale, whether its data is unavailable, or why it appeared empty.
