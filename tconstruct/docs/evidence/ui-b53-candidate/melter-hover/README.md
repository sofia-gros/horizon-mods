The screenshot and saved data do not establish the exact root cause. Relevant inspection points: `part-draw.rs` and `station-result-tooltip.rs` both read Melter metadata via `source-melter-store::read` from `game.world`; verify client position/metadata and atlas access before changing the implementation.
