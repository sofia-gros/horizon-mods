# Mighty Smelting: Seared Blocks

The source Smeltery showcase slot now exposes a bounded Seared Blocks page.
It explains default floor/wall eligibility and the existing Grout → Seared
Brick → Seared Bricks crafting chain. The source item-tag selector now resolves a bounded set of registered
items from the current world and cycles their icons. See
[showcase behavior and limits](book-showcase-tags.md).

Source identity/order, default tag membership, quantities, native recipes and
packaging have regression coverage. Actual GUI, crafting, formed structures,
save/reload and LAN remain unverified. No new recipes or machine behavior are
introduced. Other omitted Mighty pages and unsupported showcase forms remain open.
