# Glowing ability (in progress)

Glowing's source recipe uses glowstone, a daylight detector and shroomlight, consumes one ability slot and permits one level. It applies to the source interactable-or-boots durability tag. Source: TConstruct `f4e77d43f39ba1047bf93ae816b7e1beaab514c2`, `ModifierRecipeProvider` and `ModifierProvider`.

The source light is `tconstruct:glow`, emits level 14, has no collision or drops, and attaches to a full solid face. A placement uses the clicked face first, then tries other supporting faces; liquid and existing glow are rejected. A surviving glow is removed when its support disappears. A successful direct placement costs five durability with cause `tconstruct:glowing`; broken tools do not place it. The source also has boot walking in low block light and projectile hit placement, with its own launch/hit wear rules. The original glow texture, model and directional blockstate are included from that pinned revision. A six-direction light-level-14 block is declared and resource preparation assigns empty collision; The support-face lookup, an update queue, source selection outline and direct right-click path are connected. Recipe and ability-slot handling use the original recipe, including Crystal reapplication. The registration and hooks have not been formally built or tested in game. Boots walking is connected to the existing local/LAN location-change path with the source radius and light conditions, but has not been built or game-tested. Left-click interaction and projectile behavior remain unimplemented.

A standalone placement selector implements the preferred face, source fallback direction order, support checks and rejection conditions; it is not yet connected to the world. Its three lightweight tests passed.

The durability hook now has a scoped modifier-cause path, so a future Glowing action can pass its actual cause through Tanned, Overslime, Unbreakable, Dense and Reinforced. The existing ordinary-wear callers still pass no cause. Limited Mixins plan and lightweight formula tests passed; no full transformation, build, game or LAN validation has been done. Direct use passes the Glowing cause on a successful placement; it has not been validated in game. The remaining source actions are required before this ability can be considered complete.
