
A work-in-progress branch imports the pinned 85 original fluid-effect JSON files into the source-pack snapshot and adds one shared resolver for the currently understood `tconstruct:mob_effect` / `add` entity form. It preserves the first matching recipe boundary and returns unknown for unsupported effects rather than falling through. This resolver is not connected to player use, combat, incoming damage, tool fluid consumption or any modifier recipe; no ability is enabled. Complete source effect applicability, level/amount arithmetic, use timing and authoritative tool/effect synchronization before treating it as functional.
