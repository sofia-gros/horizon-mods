# Translations (i18n)

Text a mod shows should be in the language the player chose. PlutoLib keeps a mod's text per language under keys such as `fluid.example.molten_copper`, looks a key up in the language the game is set to, and tells you when the player switches language. This is not part of Fabric API; it is one of PlutoLib's own modules. This page first walks through using it, then lists every item in the [Reference](#reference).

## Basic Example

Register the text of each language once, when your mod starts. Then ask for text by key wherever you need it:

```rust
use pluto_lib::{I18n, Translations};

Translations::register("en_us", [("example.greeting".to_owned(), "Hello, %s!".to_owned())]);
Translations::register("ja_jp", [("example.greeting".to_owned(), "こんにちは、%s！".to_owned())]);

let text = I18n::translate_args("example.greeting", &["Alex"]);
// the text is in the language the game is set to; en_us unless the player chose another
assert!(text == "Hello, Alex!" || text == "こんにちは、Alex！");
```

`%s` takes the next argument; `%1$s`, `%2$s` take numbered ones, so a translation can put the arguments in the order its language needs. `%%` is a percent sign.

## Language Files

A language file is a JSON object of keys and texts, the same format as the game's `lang/en_us.json`. If your text already lives in files, read them with `Translations::register_json` instead of listing entries by hand:

```rust
use pluto_lib::Translations;

let read = Translations::register_json("en_us", r#"{ "example.title": "Example", "example.hint": "Press %s to open" }"#).unwrap();
assert_eq!(read, 2);
```

The game's own language files, including resource packs, are consulted as well: a key the player's resource pack translates wins over nothing, and your registered text for the language in use wins over the game's.

## What Happens When a Translation Is Missing

A missing translation never breaks anything. For a key and a language PlutoLib tries, in order: your text for the language in use, the game's language files, your `en_us` text, and finally the key itself. A key showing on screen therefore means "nobody translated this", and is easy to spot:

```rust
use pluto_lib::I18n;

assert_eq!(I18n::translate("example.nobody_translated_this"), "example.nobody_translated_this");
assert!(!I18n::has("example.nobody_translated_this"));
```

## Switching the Language

The player changes the language in the options. A mod that draws text every frame needs nothing: it asks for the text each time and gets the current language. A mod that **caches** text (a string built once and kept) must rebuild it when the language changes, which `LanguageEvents::CHANGED` tells it, checked every game tick:

```rust
use pluto_lib::{I18n, LanguageEvents, Translations};
use std::sync::Mutex;

static TITLE: Mutex<String> = Mutex::new(String::new());

Translations::register("en_us", [("example.title".to_owned(), "Example".to_owned())]);
Translations::register("ja_jp", [("example.title".to_owned(), "サンプル".to_owned())]);

fn rebuild() {
    *TITLE.lock().unwrap() = I18n::translate("example.title");
}
rebuild();
LanguageEvents::CHANGED.register(|change| {
    println!("language: {} -> {}", change.previous, change.current);
    rebuild();
});
```

> **Tip.** To see a translation without changing the game, use `I18n::translate_in("ja_jp", key)`. In a test, `I18n::use_language(Some("ja_jp"))` makes the whole process answer in that language until you pass `None`.

## Writing to a Player in Their Language

On a server the language that matters is each player's, not the server's. `ServerPlayer::language` gives the language option of the player's client, and `translate_in` looks the text up in it:

```rust
use pluto_lib::{with_ops, I18n, MemoryPlayerOps, ServerPlayer, Translations};

Translations::register("en_us", [("example.welcome".to_owned(), "Welcome!".to_owned())]);
Translations::register("ja_jp", [("example.welcome".to_owned(), "ようこそ！".to_owned())]);

fn welcome(player: &ServerPlayer) {
    let text = I18n::translate_in(&player.language(), "example.welcome");
    player.send_message(&text);
}

let player = ServerPlayer { uuid: 1, name: "Alex".into() };
let mut game = MemoryPlayerOps { language: "ja_jp".to_owned(), ..Default::default() };
with_ops(&mut game, || welcome(&player));
assert_eq!(game.told, [(1, "ようこそ！".to_owned())]);
```

## Translating a Fluid

A fluid has a translation key, `fluid.<namespace>.<path>`, and a display name taken from it in the language in use. Register the names and ask the registry:

```rust
use pluto_lib::{FluidDef, FluidRegistry, I18n, Identifier, Translations};

FluidRegistry::register(FluidDef::new(Identifier::new("example", "molten_copper").unwrap()).temperature(1100));
Translations::register("en_us", [("fluid.example.molten_copper".to_owned(), "Molten Copper".to_owned())]);
Translations::register("ja_jp", [("fluid.example.molten_copper".to_owned(), "溶けた銅".to_owned())]);

assert_eq!(FluidRegistry::display_name_in("en_us", "example:molten_copper").unwrap(), "Molten Copper");
assert_eq!(FluidRegistry::display_name_in("ja_jp", "example:molten_copper").unwrap(), "溶けた銅");

// in the language the game is set to
I18n::use_language(Some("ja_jp"));
assert_eq!(FluidRegistry::display_name("example:molten_copper").unwrap(), "溶けた銅");
I18n::use_language(None);
```

## Reference

### `FALLBACK_LANGUAGE`

`const FALLBACK_LANGUAGE: &str = "en_us"`. The language every lookup falls back to.

```rust
use pluto_lib::FALLBACK_LANGUAGE;

assert_eq!(FALLBACK_LANGUAGE, "en_us");
```

### `Translations`

Registers text per language.

```rust
use pluto_lib::Translations;

Translations::register("en_us", [("example.k".to_owned(), "v".to_owned())]);
```

### `Translations::register`

`fn register(language: &str, entries: impl IntoIterator<Item = (String, String)>)`. Adds `entries` (key and text) for `language` (`en_us`, `ja_jp`, ...). A key registered again replaces the earlier text.

```rust
use pluto_lib::{I18n, Translations};

Translations::register("de_de", [("example.cheers".to_owned(), "Prost!".to_owned())]);
Translations::register("de_de", [("example.cheers".to_owned(), "Zum Wohl!".to_owned())]);
assert_eq!(I18n::translate_in("de_de", "example.cheers"), "Zum Wohl!");
```

### `Translations::register_json`

`fn register_json(language: &str, json: &str) -> Result<usize, serde_json::Error>`. Adds the entries of a language file (a JSON object of keys and texts); returns how many were read, or the error if the text is not such an object.

```rust
use pluto_lib::Translations;

assert_eq!(Translations::register_json("en_us", r#"{"example.a": "A"}"#).unwrap(), 1);
assert!(Translations::register_json("en_us", "[1, 2]").is_err());
```

### `Translations::languages`

`fn languages() -> Vec<String>`. The languages something was registered for, sorted.

```rust
use pluto_lib::Translations;

Translations::register("fr_fr", [("example.bonjour".to_owned(), "Bonjour".to_owned())]);
assert!(Translations::languages().contains(&"fr_fr".to_owned()));
```

### `I18n`

Looking text up in the language the game is set to.

```rust
use pluto_lib::I18n;

assert!(!I18n::language().is_empty());
```

### `I18n::language`

`fn language() -> String`. The code of the language in use: the one set with `use_language`, else the game's, else `en_us`.

```rust
use pluto_lib::I18n;

I18n::use_language(Some("ja_jp"));
assert_eq!(I18n::language(), "ja_jp");
I18n::use_language(None);
```

### `I18n::use_language`

`fn use_language(language: Option<&str>)`. Uses `language` instead of the game's until called with `None`. For tests, and for code that writes for one player.

```rust
use pluto_lib::I18n;

I18n::use_language(Some("de_de"));
assert_eq!(I18n::language(), "de_de");
I18n::use_language(None);
```

### `I18n::translate`

`fn translate(key: &str) -> String`. The text for `key` in the language in use: what a mod registered, then what the game's language files say, then the `en_us` text, then the key itself.

```rust
use pluto_lib::{I18n, Translations};

Translations::register("en_us", [("example.plain".to_owned(), "Plain".to_owned())]);
assert_eq!(I18n::translate("example.plain"), "Plain");
assert_eq!(I18n::translate("example.unknown"), "example.unknown");
```

### `I18n::translate_in`

`fn translate_in(language: &str, key: &str) -> String`. The text for `key` in `language` (what a mod registered for it, else `en_us`, else the key), whatever the game is set to.

```rust
use pluto_lib::{I18n, Translations};

Translations::register("en_us", [("example.word".to_owned(), "Tree".to_owned())]);
Translations::register("ja_jp", [("example.word".to_owned(), "木".to_owned())]);
assert_eq!(I18n::translate_in("ja_jp", "example.word"), "木");
assert_eq!(I18n::translate_in("fr_fr", "example.word"), "Tree", "no French text: en_us");
```

### `I18n::translate_args`

`fn translate_args(key: &str, args: &[&str]) -> String`. `translate` with arguments: `%s` takes the next argument, `%1$s` and `%2$s` the numbered ones, `%%` is a percent sign.

```rust
use pluto_lib::{I18n, Translations};

Translations::register("en_us", [("example.swap".to_owned(), "%2$s before %1$s".to_owned())]);
assert_eq!(I18n::translate_args("example.swap", &["a", "b"]), "b before a");
```

### `I18n::has`

`fn has(key: &str) -> bool`. Whether any text is registered or known to the game for `key` in the language in use or `en_us`.

```rust
use pluto_lib::{I18n, Translations};

Translations::register("en_us", [("example.exists".to_owned(), "yes".to_owned())]);
assert!(I18n::has("example.exists"));
assert!(!I18n::has("example.missing"));
```

### `LanguageChange`

What the changed event receives. `previous` is the code of the language before, `current` the code now.

```rust
use pluto_lib::{LanguageChange, LanguageEvents};

LanguageEvents::CHANGED.register(|change: &LanguageChange| assert_ne!(change.previous, change.current));
LanguageEvents::CHANGED.invoke(&LanguageChange { previous: "en_us".into(), current: "ja_jp".into() });
```

### `LanguageEvents`

Events about the language.

```rust
use pluto_lib::LanguageEvents;

LanguageEvents::CHANGED.register(|_| {});
```

### `LanguageEvents::CHANGED`

The player changed the language option (checked every game tick). Rebuild anything you cached in the old language.

```rust
use pluto_lib::{LanguageChange, LanguageEvents};
use std::sync::atomic::{AtomicU32, Ordering};

static REBUILDS: AtomicU32 = AtomicU32::new(0);
LanguageEvents::CHANGED.register(|_| {
    REBUILDS.fetch_add(1, Ordering::Relaxed);
});
LanguageEvents::CHANGED.invoke(&LanguageChange { previous: "en_us".into(), current: "fr_fr".into() });
assert_eq!(REBUILDS.load(Ordering::Relaxed), 1);
```
