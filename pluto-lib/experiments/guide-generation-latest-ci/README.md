# Latest native Font generation six CI candidate

Source-only controller, not a run result. Publish to a nontrigger checkpoint first.
The sole trigger is the dedicated public branch recorded in inputs; contents-read
and a standard Ubuntu runner only. Execution needs a separate serial release.
No ordinary API, manifest, transport, LAN or prior owned-opening CI is changed.

The unchanged a111 preparer and d194 generation consumer are the inputs. Actual
latest official f4dc core/render and the exact 29-file API are compiled cold under
Rust 1.95, with the official lock's identities and three path patches. The two
reviewed Guide runner utility files are imported unchanged for disk, root/Rustup/
Cargo filesystem coverage, process-group teardown, compact logs, source seals and
strict metadata stdout. Their old official constants and old experiment flows
are not executed. There is no Mixins, host patch or Game compilation here.

Locked dependency fetch precedes offline fixture resolution. Only the owned
fixture lock may adapt, then locked metadata must match. Three actual rustc
invocations (core, render, fixture test) and one exact Cargo artifact with `fresh: false` are required.
All compilation ends before binary/source/OUT_DIR sealing. That same executable
is invoked twice: exact sorted 21-name terse inventory, then generation's six
names with 15 filtered and zero failures/ignored. The twelve older consumer cases
and three converter cases are only compiled and inventoried, not rerun. Their
old 624c proof remains a separate result, never upgraded to latest by compilation.

The native fixture uses its original synthetic metric/bitmap input, not an
unapproved Minecraft asset tree. It checks split/chunk/query values and CPU glyph
patch ordering/full-region fallback. It does not establish GPU execution, visible
17-line drawing, performance/allocation equivalence, actual Client input, language
reload, retained screen authority/lifetime, LAN behavior or installed composition.

The normal 10 GiB + 128 MiB floor plus 2 GiB setup reserve covers all commands,
including apt/rustup. Inner preparation is pure and inherits its outer PGID; it
cannot launch metadata or another process group. Every failure prints a false
partial receipt with completed gates and rechecks available source/lock/file/
mode/link/OUT_DIR/binary seals. Raw logs remain ephemeral in the runner; the console
contains byte/hash receipts and bounded diagnostics, not claimed downloadable raw
artifacts. No cache/artifact upload or billing/permissions change is requested.
