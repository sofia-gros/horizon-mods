# Credits — Pipes mod

## Pipe textures (original work)

The four pipe block textures in `content/assets/pipes/textures/block/`
(`item_pipe.png`, `extraction_pipe.png`, `fluid_pipe.png`,
`fluid_extraction_pipe.png`) are original pixel art drawn for this mod.
Their visual language — a slim glass transport tube with material collars,
iron-grey for the plain pipes and wood-brown for the extraction pipes —
follows the classic transport-pipe look popularised by BuildCraft, but no
BuildCraft file (or any other third-party asset) is used: every pixel was
drawn for this mod's own pipe geometry (a 6-pixel tube on the vanilla
default-UV layout), and the textures are covered by this repository's own
licence terms like the rest of the mod.

Earlier beta builds shipped BuildCraft's own texture files unmodified
under the Minecraft Mod Public License (MMPL); those files were removed
when the textures were redrawn, because the originals are laid out for
BuildCraft's pipe dimensions and render stretched on this mod's pipes.
No third-party texture attribution is therefore required any more.

## Package icon (original work)

The package icon (`icon.png` beside the manifest) is original pixel
art drawn for this mod: a pipe cross junction with material collars
on a dark ground, in the same visual language as the pipe textures
above.

The original Classic Pipes logo (J4gm/classicpipes,
`common/src/main/resources/logo.png`) was considered and NOT used.
That repository's only license file (LICENSE.md, checked against the
repository on 2026-11-27) is the full Creative Commons
Attribution-NonCommercial-ShareAlike 4.0 International text, and no
separate asset license exists, so the logo is CC BY-NC-SA 4.0
material — incompatible with this mod's MIT release, the same ruling
the project already applies to that mod's textures. No part of the
logo is reproduced in the icon.
